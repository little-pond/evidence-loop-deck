# Evidence Loop Deck — QuickBooks SMB Marketing

Single-file interactive HTML slide deck ("From evidence to better decisions") for the
Intuit QuickBooks SMB marketing exercise — *Design and Prototype the Loop*.

- **`index.html`** — the entire deck (self-contained; CDN fonts + Lucide, local divider images).
- **`images/`** — full-bleed section-divider backgrounds.

Open `index.html` in any browser (← → to navigate · `B` toggles motion · `ESC` for the index).

10 main slides → closing → Q&A. Built with the `guizang-ppt-skill` Swiss style, rebranded to the QuickBooks design system.
